How publishing works: this site is static (GitHub Pages), so there's no live database — "Save draft" only previews changes in this browser. When you're happy with your edits, click "Export site-data.json" and replace /data/site-data.json in your GitHub repo with the downloaded file, then commit. GitHub Pages will redeploy automatically within a minute or two.
